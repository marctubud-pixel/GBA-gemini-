# 本机作品管理

后台现已可用，入口是 **`http://127.0.0.1:3012/admin`**。个人主页继续使用 `http://127.0.0.1:3012/`。后台和前台由同一个本机服务提供；关闭服务时两个页面均无法访问。

## 启动

在项目目录安装依赖后，开发预览：

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 3012 --strictPort
```

使用构建后的版本：

```sh
npm run build
npm run start
```

后台仅限本机访问，不需要在线账号；它不是已部署的互联网管理系统。不能把开发服务直接作为公开后台使用。在线账号、数据库和文件存储将在后续连接。

## 编辑和上传

1. 左侧选择文案、品牌、影像、兴趣、实验室或游戏板块，再选择分类。
2. 点击分类下方的 **“＋ 添加作品”**，填写项目名称和一句简介；也可点击已有作品编辑。新增作品会使用当前板块和分类，不受原有占位数量限制。
3. 点击 **“上传 / 替换封面”** 添加图片，选择 **“封面比例”**（4:3、16:9、9:16、1:1 或原始比例），左侧即时预览。默认完整显示不裁切，也可选择居中裁切填满画框；不改动原文件。影院、品牌折页、游戏列表和兴趣展柜读取同一封面设置。封面比例与详情画面比例分别保存。
4. 点击 **“上传系列图片”** 或 **“上传视频”**。图片支持 JPEG、PNG、WebP、GIF；视频支持 MP4、WebM，可以多选。下方立即出现图片或可播放的视频预览。系列画面可以前移、后移、移除或设为封面；替换封面时由它生成的视频海报也会同步更新。
5. 品牌方案等点击 **“上传项目 PDF”** 即可选择文件，不需要预先切换详情方式。上传后自动设为 PDF 连续阅读，可在页面里滚动、拖动和放大；也可选择图片 / 视频或外部链接，外部链接直接在新窗口打开，例如飞书文档。原平台的文档权限仍由你设置。
6. 选择 **“详情画面比例”**。H5 使用竖屏，唱片使用正方形，海报 / 视频可使用 16:9；详情通过留边保留全部画面，不拉伸裁切。H5 的实际体验地址可填入“体验链接”。目前不托管可执行的 HTML / H5 程序包。
7. 点击编辑区顶部或底部的 **“游戏中预览”**，直接进入当前作品所在房间的真实游戏界面。可以预览尚未保存的名称、简介、封面、视频和 PDF，包括新建作品；先等待文件上传完成。切换 **“房间界面” / “作品详情”** 查看两种呈现，游戏经历保留列表视角。预览中仍可使用游戏按键，点击“房间界面”可重新定位当前作品；关闭预览后继续编辑原草稿。预览默认静音，不会自动保存或改变其他前台标签页。
8. 确认预览后点击 **“保存到作品库”**。上传完成但未保存的项目修改不会出现在正式前台。另一前台标签页会收到更新；切回前台时也会重新读取内容。

书籍、黑胶和照片分别进入 Hobby Studio 对应的架子。视频在影院或作品阅读层内播放。游戏经历只需封面、名称与体验时长；游戏互动可继续配置大图、PDF 或体验链接。

PDF 文件最大 50 MB，图片最大 50 MB，视频最大 250 MB。视频需使用浏览器能播放的编码；推荐 MP4 的 H.264 / AAC 或 WebM。密码保护的 PDF 应先导出可直接阅读的版本。上传是本机操作，不会发送文件到第三方。

## 保存、备份和迁移

默认目录：项目根目录下的 **`.portfolio-data`**。

- `content.json`：当前作品信息及版本号。
- `uploads/`：原始上传文件，随机文件名避免重名覆盖。
- `backups/`：每次保存前的上一版信息。

首次使用会以现有简历占位建立作品库。后续启动或构建不会覆盖这份作品库，也不会修改 `src/data/resumeEntries.json`。删除项目或移除画面只是取消引用，原文件仍保留；这可以减少误删，但不会自动释放磁盘。

后台“导出内容清单”仅下载 JSON。**完整备份请复制整个 `.portfolio-data` 目录**，包含上传文件。恢复时先停止服务，再用选定备份替换 `content.json`，保留 `uploads/` 后重新启动。多个编辑页同时保存时，旧版本会被拒绝；未保存草稿保留在页面，重新载入前请先记录改动。

可通过启动环境变量 `PORTFOLIO_DATA_DIR` 指定其他专用存储目录。不要指定 `public`、`dist` 或临时目录。`.env.example` 的 `VITE_CONTENT_URL` 是前台读取源的可选覆盖项，默认无需设置；设置远程读取源后，本机后台不会写入远程服务。

本机上传目录已经排除在 Git 之外。推送代码到 GitHub 不会上传这些文件，也不会让它们自动显示在在线网站。后续迁移需要把文件放入在线存储，更新媒体 URL，再连接数据库与登录权限；现有板块、展示比例及 PDF / 链接配置可以继续使用。

影院票面保持固定的 16:9 图片位置和信息行，长影片名在单行中滚动显示。每部影片在「影片详情链接（二维码）」填入公开网址后，票根自动生成二维码，支持扫码或点击打开；留空时显示待添加。上传视频后，在电影票下点播放或按 J，进入全屏播放器；K / ESC 返回电影票。后台游戏预览也支持全屏播放。

「游戏互动」的「展示类型」可选 H5、Demo、短片、互动原型或游戏，列表在名称旁显示对应类型。已有简历项目根据其明确的 H5 / Demo 描述识别类型；后续可在后台修改。
