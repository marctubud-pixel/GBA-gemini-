## 内容边界

- `isSample: false` 表示名称和介绍有简历依据，不表示详情、视频或 Demo 已齐备。`source` 标明简历页码。
- 《宋驭山河》原文继续保留在数据中，文字工坊详情按本轮布局显示短项目概述和影片入口。其他文案展示作品图，完整文字和创意说明待整理。
- 包装、视觉和 IP 项目按简历描述为创意/策划。没有把项目角色扩展为独立完稿或全套品牌识别设计。
- 《墨杀·三千怨》明确全流程个人制作；《我是谁》明确美术设计。分镜图按分镜片段展示，不当作完整影片。
- 游戏列表只统计有数字的 12 项，共 902 h。简介保留简历自述的累计核心游戏体验 1000h+；未列明时长的其他体验不计入列表合计。
- 《声音杂货铺》保留“项目获腾讯广告创益突破奖”，不写成个人独立获奖。
- 影片时长、制作日期、Demo、视频、文档、附件、文件大小及实验状态未获确切资料，均留空。相应播放/打开按钮显示待添加并禁用。
- 简历中的二维码未转成链接。未公开手机、微信或具体住址。联系入口使用简历邮箱。
- 阅读、黑胶、骑行、私人观影、手办收藏缺少简历事实，因此保留空态。摄影摄像只计入技能，未据此编造摄影作品集。

## 建议下一轮调整

1. **品牌馆名称**：实际内容更偏创意策划。可以把四列进一步调整为“IP / 视觉策划 / 包装创意 / 电商传播”，避免访客把策划作品误解为独立设计完稿。目前保留 IP、视觉、品牌、电商，另增加“线下”展览占位。去除编号、栏内分页与查看按钮，封面或 J 直接打开完整大图与项目信息；放大层支持前后项目切换。
2. **影院内容分组**：成片、美术与分镜都在同一选片轮播里，8 项可验证版式。素材齐备后适合增加“成片 / 美术与分镜”切换，成片进入播放器，分镜进入图册。
3. **主案例与过程档案**：《辨鬼》与两项主策 H5 放在游戏互动列表，列表只显示小图和名称，打开完整大图展示玩法及个人角色；游戏经历由另一台街机单独打开，行内仅图片、名称、体验时长。实验室右侧只留标题、简介和详情入口，完整层补流程图、版本记录和复盘。游戏求职方向可优先展示这三项。
4. **文字工坊**：固定 TVC / 品牌 / 电商 / 人群四类。预览只保留名称、简介和查看系列；详情左侧竖图组合或影片入口，右侧项目名称和概述，图片支持独立放大。品牌文案暂空，其余按现有作品占位，后续补项目详情与影片。
5. **兴趣展柜**：五类导航已经确定，右侧改为照片架、书架、唱片封面与电影海报架。下一轮补个人摄影、阅读书封、唱片封面、观影记录及骑行图片；当前实际素材未提供，不把临时排版样例当成私人收藏。
