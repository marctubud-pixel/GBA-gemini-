## 内容边界

- `isSample: false` 表示名称和介绍有简历依据，不表示详情、视频或 Demo 已齐备。`source` 标明简历页码。
- 《宋驭山河》保留简历原文。其他文案先展示作品图，完整文字和创意说明待整理。
- 包装、视觉和 IP 项目按简历描述为创意/策划。没有把项目角色扩展为独立完稿或全套品牌识别设计。
- 《墨杀·三千怨》明确全流程个人制作；《我是谁》明确美术设计。分镜图按分镜片段展示，不当作完整影片。
- 游戏列表只统计有数字的 12 项，共 902 h。简介保留简历自述的累计核心游戏体验 1000h+；未列明时长的其他体验不计入列表合计。
- 《声音杂货铺》保留“项目获腾讯广告创益突破奖”，不写成个人独立获奖。
- 影片时长、制作日期、Demo、视频、文档、附件、文件大小及实验状态未获确切资料，均留空。相应播放/打开按钮显示待添加并禁用。
- 简历中的二维码未转成链接。未公开手机、微信或具体住址。联系入口使用简历邮箱。
- 阅读、黑胶、骑行、私人观影、手办收藏缺少简历事实，因此保留空态。摄影摄像只计入技能，未据此编造摄影作品集。

## 建议下一轮调整

1. **品牌馆名称**：实际内容更偏创意策划。可以把四列进一步调整为“IP / 视觉策划 / 包装创意 / 电商传播”，避免访客把策划作品误解为独立设计完稿。目前保留四列结构，艺术列先改为“视觉”。
2. **影院内容分组**：成片、美术与分镜都在同一选片轮播里，8 项可验证版式。素材齐备后适合增加“成片 / 美术与分镜”切换，成片进入播放器，分镜进入图册。
3. **主案例与过程档案**：《辨鬼》与两项主策 H5 放在游戏厅展示玩法及个人角色，实验室补流程图、版本记录和复盘，不重复完整项目说明。游戏求职方向可优先展示这三项。
4. **文字工坊**：WORDS 先放现有文案。IDEA、LIFE 与品牌文案目前空置，后续用真实创意推导、品牌文案或个人手记补齐。
5. **兴趣展柜**：游戏记录已经能验证版式。下一轮可补个人摄影、阅读/观影记录及骑行图片，再决定是否保留全部七类。

## 文件与后台接口

- 默认集合：`src/data/resumeEntries.json`，由 `contentSeed.ts` 通过与 HTTP 接口相同的校验读取。
- 可独立读取的集合：`public/content/portfolio.resume.json`。
- 媒体：`public/media/resume/`，保留原图比例并压缩为 WebP，60 张作品图约 7.7 MiB。缺素材的项目继续使用像素示意图。
- `public/content/portfolio.example.json` 保留旧示例文件用于接口测试。配置 `VITE_CONTENT_URL=/content/portfolio.resume.json` 可测试这份实际占位集合。
- 后台继续只预留 HTTP 内容读取接口，未增加上传、管理页面或发布操作。
