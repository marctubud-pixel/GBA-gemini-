# 海岛旅程与六个内景

开发预览：`npm install` 后运行 `npm run dev`。生产检查：`npm run build`，再运行 `npm run preview`。

START GAME / J 先进入至少 2.2 秒的像素加载过渡，同时等待 WorldScene 就绪。期间键盘、GBA 控件和索引 / 简历切换锁定，防止跳过动画或积累移动输入。开场、加载与结束 UI 按 640 × 360 虚拟坐标缩放，与像素背景一致。

文案工坊、品牌馆、影院、游戏厅、个人兴趣工作室和实验室使用程序绘制的内景。室内角色的精灵缩放为 1.4、相机为 1；外景步行精灵为 1、相机为 1.4，屏幕显示高度一致。物件在人物靠近或鼠标悬停时显示轻微发光边框，可以直接点击；走近后 J / E 也可查看。室内只保留小型按键提示，不再给每个物件写查看说明。家具、打字机、自行车、机器人与实验设备按角色的可见高度校准，保持清晰像素轮廓，并用接触阴影、侧面暗部及墙面投影区分层次。室内画面省略重复场景名和微小标语，作品面板保留标题与必要内容。六种面板顶部使用主题徽章、海岸小景与纸张细节。A / D 和左右方向键负责步行。带海景窗的房间使用同一时间驱动云、海浪与帆船，海报保持静态。

顶部“退出内景”或 ESC 可以从房间任意位置返回对应建筑门口。作品面板中的 K / ESC 先返回上一层或关闭面板；再次 ESC 退出房间。外景建筑门、停靠单车、猫和望远镜支持点击。

骑过山顶观光区后继续向右，角色跨过当前相机的右边界并离屏，才显示 THANK YOU FOR EXPLORING。结束菜单支持方向选择和 J 确认，CONTACT 内的 K / ESC 返回留念菜单；EXPLORE AGAIN 将角色与单车恢复到起点骑行状态。改变视图或传送会取消尚未完成的骑出动画和回调。

六个作品 UI 和全览索引共用内容集合。实验室提供影像 / 游戏 / 交互 / 品牌 / 视觉五类日志、正文、状态、日期、文档、附件与实际视频 / Demo。未添加的媒体入口禁用，示例记录明确标注。后台本轮只预留读取接口；上传与管理功能留待后续，参见 [content-api.md](content-api.md)。个人资料中的示例邮箱不作为实际联系地址。

## 后续：全地图昼夜

本轮不实现昼夜切换。后续统一设计整个地图与六个内景的白天 / 夜晚模式：夜间开启室外路灯、建筑窗光与室内灯光，窗外海景同步变为夜景，并统一处理人物、材质、阴影与界面可读性。后台上传管理功能仍作为另一个后续阶段。
