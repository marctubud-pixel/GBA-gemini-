# 海岛旅程与六个内景

开发预览：`npm install` 后运行 `npm run dev`。生产检查：`npm run build`，再运行 `npm run preview`。

START GAME / J 先进入至少 2.2 秒的像素加载过渡，同时等待 WorldScene 就绪。期间键盘、GBA 控件和索引 / 简历切换锁定，防止跳过动画或积累移动输入。开场、加载与结束 UI 按 640 × 360 虚拟坐标缩放，与像素背景一致。

文案工坊、品牌馆、影院、游戏厅、个人兴趣工作室和实验室使用程序绘制的内景。室内角色的精灵缩放为 1.4、相机为 1；外景步行精灵为 1、相机为 1.4，屏幕显示高度一致。物件在人物靠近或鼠标悬停时显示轻微发光边框，可以直接点击；走近后 J / E 也可查看。室内只保留小型按键提示，不再给每个物件写查看说明。家具、打字机、自行车、机器人、实验设备及街机恢复到上一版本的尺寸与位置；室内外角色仍保持相同的屏幕高度。保持清晰像素轮廓，并用接触阴影、侧面暗部及墙面投影区分层次。室内画面省略重复场景名和微小标语，作品面板保留标题与必要内容。六种作品面板以浮窗叠加在内景上，浮窗接近满屏，四周保留当前房间的可见边缘。浮窗约占游戏画面 94% 宽，上方预留独立的 ESC / 关闭按钮区域，背景压暗并模糊；顶部按六类参考分别采用书册标签、贝壳拱牌、影院横幅、游戏机、收藏册书脊、实验档案标签的造型，减少细碎阶梯折角，并用侧边、亮边与底部暗面表现厚度。顶部只保留放大的主标题，副标题不再显示，操作说明集中到底部。作品正文、分类与按钮同步放大。长内容在面板内部滚动，品牌案例与影院操作按钮保持可见；关闭入口位于弹窗外侧，不在顶部牌匾放叉号；兴趣标题居中，书脊线避开文字。关闭面板仍留在当前房间。A / D 和左右方向键负责步行。带海景窗的房间使用同一时间驱动云、海浪与帆船，海报保持静态。

顶部“退出内景”或 ESC 可以从房间任意位置返回对应建筑门口。作品面板中的 K / ESC 先返回上一层或关闭面板；再次 ESC 退出房间。外景建筑门、停靠单车、猫和望远镜支持点击。

骑过山顶观光区后继续向右，角色跨过当前相机的右边界并离屏，才显示 THANK YOU FOR EXPLORATION。留念页只有居中的英文致谢、中文“谢谢你的参观”和 VIEW RESUME / CONTACT / EXPLORE AGAIN 三个按钮；按钮缩为 94 × 24 逻辑像素并置于画面底部，避开自行车与背包；移除右上红叉、额外标语、底部说明及右侧海岸小屋，保留山顶观测站与动态海景。结束菜单支持方向选择和 J 确认，CONTACT 内的 K / ESC 返回留念菜单；EXPLORE AGAIN 将角色与单车恢复到起点骑行状态。改变视图或传送会取消尚未完成的骑出动画和回调。

六个作品 UI 和全览索引共用内容集合。实验室左侧保留影像 / 游戏 / 交互 / 品牌 / 视觉五类档案柜，右侧只显示项目名称、简介首句和查看详情。点击直接进入全部原图与完整介绍，文档、附件和 Demo 在同层直接打开，视频保留原生控制；无日志或附件二级菜单。游戏厅两台街机分别打开游戏经历与游戏互动；经历仅图片、名称与体验时长，互动仅图片与名称，点击整行或 J 直接打开完整大图。两种列表初始画面均完整显示至少三项，不再放双分类按钮、右侧预览或底部返回游戏厅。W / S 浏览列表或选择档案，完整项目 A / D 切换、W / S 阅读，K / ESC 返回当前集合；房间比例不变。内容接口继续预留实验状态、日期与文件大小字段，但简洁预览不显示。缺失素材和时长明确待补充，不添加虚假媒体或链接。后台本轮只预留读取接口；上传与管理功能留待后续，参见 [content-api.md](content-api.md)。默认内容已按简历占位，资料页使用真实介绍、工作经历与邮箱，见 [resume-placement.md](resume-placement.md)。

兴趣工作室的顶部采用蓝色收藏册边框与奶油色标题牌，补相片、相机、唱片、书籍、缝线和纸页细节，装饰避开居中主标题。兴趣工作室保留 Photography / Reading / Vinyl / Cycling / Film 五类导航，移除 Games 与 Figures 入口及对应游戏收藏热点。右侧只展示照片架、书封、方形唱片封面、骑行图片与电影海报架，不重复分类标题，也不放 VIEW / OPEN COLLECTION / BACK 按钮。W / S 切分类，A / D 选择收藏，点击或 J 直接查看原图与已有视频；大图 A / D 切换，K / ESC 返回当前选中项并恢复焦点。书籍、唱片、电影每个条目在架上仅一张封面，其他媒体仍可在原图层切换。原游戏兴趣数据保留在集合中，未被删除。其余个人兴趣素材尚未提供，默认五类显示空展柜，临时验证素材不打包发布。

## 后续：全地图昼夜

本轮不实现昼夜切换。后续统一设计整个地图与六个内景的白天 / 夜晚模式：夜间开启室外路灯、建筑窗光与室内灯光，窗外海景同步变为夜景，并统一处理人物、材质、阴影与界面可读性。后台上传管理功能仍作为另一个后续阶段。

兴趣馆与片尾复核：61 项浏览器检查通过，包括五类空态、HTTP 媒体、直接原图、书封与方形唱片、缺素材、真实视频、焦点与键盘、实际骑出后片尾、精简文字与居中、观测站保留和三个操作。无 JavaScript 错误；临时封面与影片仅在浏览器注入，未加入真实集合。
